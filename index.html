Computer Networking

Computer networking links computers for shared resources through the internet.

Networking requires computers to access multiple networks and share their resources for computer operations, including:

  • Web browsing
  • Sending and retrieving emails
  • Sharing files and images
  • Downloading music

Organizations such as companies, schools, and government agencies use single-user or general-purpose computer networks for:

Network Categories

Personal Area Network (PAN)

The smallest type of network with a limited span. It interconnects compatible personal devices.

Example: Wireless earphones connected to a smartphone, or a computer connected to a printer.

Network Categories

Local Area Network (LAN)

Used to interconnect and share computer resources in an establishment such as a corporate building, house, or several buildings in a limited area.

Example: Office computers sharing one printer and one router inside a company building, or the devices in your home.

Network Categories

Campus Area Network (CAN)

An enterprise network covering multiple buildings in a campus environment.

Example: A university network that links the library, classrooms, and admin office together.

Network Categories

Metropolitan Area Network (MAN)

Covers multiple city buildings, traffic lights, and parking meters, connecting wirelessly as a metropolitan area network.

Example: A city linking its offices, traffic lights, and parking meters wirelessly under one network.

Network Categories

Wide Area Network (WAN)

A much larger network covering vast areas, such as cities, provinces, and countries. WAN can also be a bigger network consisting of LANs and MANs.

Example: The internet, or a company connecting branch offices in different cities and countries.

  • Bring users and devices together in campuses and branches.
  • Link employees in a corporate building.

Example: Employees' laptops and phones connect through Wi-Fi and a switch inside the office building, then out to the wider network.

2. Networks for Data Centers

  • Link multiple servers with data and applications.
  • Make data and applications easily accessible to users.

Example: A company's racks of servers store its databases and apps, and staff reach them with one click through the data center network.

The Open Systems Interconnection Model

The Open Systems Interconnection (OSI) reference model of the International Organization for Standardization was developed in 1984 as an open standard for every communication system to allow the interlinking of different types of networks.

The OSI reference model has seven layers describing networking functions, from the physical network interface to the software application interface.

The OSI model aims to provide a structure for networking that ensures compatibility in the network hardware and software and expedites the advancement of upcoming networking technologies.

The Seven Layers of the OSI Model

Layer 1Physical Layer
Layer 2Data Link Layer
Layer 3Network Layer
Layer 4Transport Layer
Layer 5Session Layer
Layer 6Presentation Layer
Layer 7Application Layer

Layer 1: Physical Layer

  • Gives electrical and mechanical connections to the network.
  • Handles signal and media.

Example: Ethernet cables and fiber optic cables carry the signals as electricity or light.

Layer 2: Data Link Layer

  • Handles error recovery, flow control, and sequencing of terminals that are either sending or receiving.
  • The media access control (MAC) layer, where MAC addressing is defined.
  • Assigned for the flow of data.

Example: A network switch learns each device's MAC address and sends data only to the right one.

Layer 3: Network Layer

  • Acts as the network controller that receives outgoing messages.
  • Combines messages and segments into packets with a header detailing the routing information.
  • Provides addressing and routing decisions.

Example: A router reads a packet's header and picks the route toward its destination.

Layer 4: Transport Layer

  • Responsible for end-to-end delivery between devices.
  • Deals with message integrity between source and destination.
  • Handles segmenting and reassembling packets.
  • Manages end-to-end delivery to ensure error-free packets.

Example: TCP splits a message into segments and puts them back together in order. UDP is a faster, lighter option.

Layer 5: Session Layer

  • Provides the control functions required to start, manage, and end connections to satisfy user requests.
  • Establishes, manages, and terminates sessions.

Example: Logging in to an online account starts a session, and logging out ends it.

Layer 6: Presentation Layer

  • Accepts and structures the messages for an application by converting the message from one code to another.
  • Processes data compression and encryption.
  • Manages protocol conversion and data translation.

Example: Encrypting a password before sending it, or compressing a file into a ZIP.

Layer 7: Application Layer

  • Interacts with application programs with communication components such as a web browser and email.
  • Responsible for recording a message, understanding the request, and identifying the information needed to support it.
  • Provides support for applications.

Example: Opening a website in a web browser, or sending a message with an email app.
